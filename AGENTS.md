# Ask before changing anything

Ask the user and wait for a clear yes before you create, change, edit, move, rename, or delete anything. This covers every file and folder (code, docs, config) and every command that changes the project, such as installing or removing packages, or git commit and push.

- When you ask, list the files and describe what will change.
- A yes covers only the change you described. Ask again for anything more, including follow-up fixes.
- Reading files and running read-only commands need no approval.
